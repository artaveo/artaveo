============================================================

should be deleted after dropping in this zip's contents. A zip can't
represent a deletion, so remove them manually in GitHub Desktop (or `git
rm`):

can be removed too (its only file moved to app/[locale]/design-system/).

Everything else in this zip is either a new file or an in-place edit to
an existing path — just drop the zip's contents into the repo root and
overwrite.

why, plus known debt items tracked for later phases.
